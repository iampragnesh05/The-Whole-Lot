THE WHOLE LOT — HOSTINGER PRODUCTION PACKAGE

UPLOAD
1. Buy/activate Hostinger Web Hosting and connect thewholelotmedia.com.
2. In hPanel → Websites → Manage → File Manager, open public_html.
3. Back up/delete any default placeholder site files.
4. Upload the contents of this package directly into public_html.
   index.html must be directly inside public_html.
5. Enable SSL in Hostinger and test https://thewholelotmedia.com.

EDITING
- Page text: edit the relevant .html file.
- Global design: assets/css/styles.css
- Shared JavaScript: assets/js/main.js
- Homepage collage images: assets/images/
- Contact destination: contact-submit.php ($to variable)

CONTACT FORM
The form posts to contact-submit.php and currently sends to hello@thewholelotmedia.com.
Create that mailbox (or replace the address) before launch. PHP mail can occasionally land in spam; for stronger delivery later, connect an SMTP/form service.

NOTES
- The production site uses Google Fonts, so fonts need an internet connection.
- Documentary images currently come from the supplied brand-guideline artwork and can be replaced later with original photography.
- robots.txt and sitemap.xml are included.
- 404.html and a custom .htaccess are included.
